# Single-Company-PWA mit ASP.NET Core, React und PostgreSQL

OpenHR wird für ein einzelnes Unternehmen als React-/TypeScript-PWA mit einer
ASP.NET-Core-REST-API und PostgreSQL gebaut. Die Kombination nutzt die
C#-Kenntnisse des Teams im Backend, das reife PWA-/WebAuthn-Ökosystem im
Frontend und lässt sich per Docker Compose sowohl EU-gehostet als auch
On-Premises betreiben; Mehrmandantenfähigkeit und eine zweite
Produktionsdatenbank werden nicht vorgezogen.
